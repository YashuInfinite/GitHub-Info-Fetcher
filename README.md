# GitHub-Info-Fetcher

A sleek, responsive web application built with vanilla HTML5, CSS3, and JavaScript that interacts with the GitHub REST API to quickly fetch user stats, repository creation dates, and repository metrics in a glassmorphic interface.

https://githubinfofetcher.netlify.app/

---

## 🌟 Key Features

- **User Insights**: Fetch total followers and account creation date by entering a username or profile URL.
- **Repo Creation Date**: Look up the exact date any public GitHub repository was created.
- **Repository Statistics**: Retrieve real-time fork counts and star counts for any public repo.
- **Smart URL Parsing**: Automatically extracts usernames and repository paths from full URLs (`https://github.com/...`) or raw handles.
- **Animated Loading State**: Built-in CSS shimmer skeleton loader while data is fetched.
- **Modern Glassmorphic UI**: Frosted glass card with backdrop blur, smooth focus effects, and subtle entrance animations.
- **100% Responsive**: Fully optimized for mobile, tablet, and desktop screens.
- **Zero Dependencies**: Pure HTML, CSS, and vanilla JavaScript—no build tools, bundlers, or node modules required for deployment.

---

## 🛠️ Built With

- **HTML5** – Semantic markup and accessibility.
- **CSS3** – Modern glassmorphism, flexbox layout, CSS variables, keyframe animations, and media queries.
- **JavaScript (ES6+)** – Asynchronous `fetch` API, DOM manipulation, and input regex validation.
- **GitHub REST API** – Live GitHub profile and repository endpoints.
